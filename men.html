レポート設定とプレビュー

プレビュー

📲 アプリとしてインストール

ホーム画面に追加するとオフラインでも利用できます

📱 iOS（iPhone / iPad）
Safariを使ってください（Chrome等では追加不可）
  1. Safariでこのページを開く
  2. 画面下の共有ボタン（□↑）をタップ
  3. 下にスクロールして「ホーム画面に追加」をタップ
  4. 名前を確認して「追加」をタップ
ホーム画面のアイコンからフルスクリーンで起動します
🤖 Android（Chrome）
  1. Chromeでこのページを開く
  2. 右上の⋮（メニュー）をタップ
  3. 「アプリをインストール」または「ホーム画面に追加」をタップ
  4. 「インストール」で確定
ホーム画面とアプリドロワーに追加されます
🪟 Windows（Chrome / Edge）
Chrome：アドレスバー右端のインストールアイコンをクリック。表示されない場合はメニュー（⋮）→「インストール」
Edge：アドレスバー右端の＋アイコン、またはメニュー（…）→「アプリ」→「このサイトをアプリとしてインストール」
スタートメニューとデスクトップにショートカットが追加されます
🍎 macOS（Chrome / Edge / Safari）
Chrome / Edge：Windowsと同様にアドレスバーのインストールアイコンまたはメニューから
Safari（macOS Sonoma 14以降）：メニューバー「ファイル」→「Dockに追加」
LaunchpadまたはDockにアイコンが追加されます

📚 男子体操競技 Dスコア計算システム

🎯 このアプリについて

男子体操競技（6種目）のDスコア計算システムです。
2025-2028年FIG採点規則 + MAG NL1-3（2025年）対応。

📱 主な機能

  • 種目：ゆか、あん馬、つり輪、跳馬、平行棒、鉄棒
  • 技入力：技名・難度（A-J）・グループ（Ⅰ-Ⅳ）を手動入力
  • a技ボタン：グループなし、難度a（0.1点）の技を追加
  • 技並び替え：ドラッグ＆ドロップで順序変更
  • 自動計算：難度点・グループ点・技数NDを自動計算
  • 組み合わせ加点：ゆかと鉄棒で手動入力可能
  • 跳馬：技名・技番号・Dスコアを手動入力
  • 目標Eスコア：各種目で目標E点を設定
  • その他ND：手動で減点を追加
  • 履歴機能：Ctrl+Z/Yで操作の取り消し・やり直し
  • 自動保存：ブラウザに自動保存（リロード後も復元）
  • レポート生成：全種目の結果をPNG画像で保存
  • PWA対応：ホーム画面に追加してオフライン利用可能

📊 計算式

Dスコア = 難度点（上位8技） + グループ点 + 組み合わせ加点
目標点 = Dスコア + 目標Eスコア − 技数ND − その他ND

📰 最新ルール変更（MAG NL1-3）

NL3（2026/1/1〜）終末技グループ点の上限
あん馬・つり輪・平行棒・鉄棒の終末技EGが最大0.5に変更。
例: F難度終末技 → グループ点 0.6 → 0.5（−0.1）
NL1/NL3 ゆかの新規ND要件（各 −0.3）
要求項目チェック欄のチェックを外すと0.3NDが加算されます：
① アクロバット技で演技開始
② バランスまたは承認済み跳躍技の実施
③ 各コーナーの移動技が異なること（2026/1/1〜）
