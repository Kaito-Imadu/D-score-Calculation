# 体操競技 Dスコア計算システム

2025-2028年FIG採点規則に対応した体操競技のDスコア計算システムです。

## 🌐 Webアプリケーション

https://kaito-imadu.github.io/D-score-Calculation/

## 📋 機能

### 男子体操（6種目）
- ゆか（FX）
- あん馬（PH）
- つり輪（SR）
- 跳馬（VT）
- 平行棒（PB）
- 鉄棒（HB）

### 女子体操（4種目）
- 跳馬（VT）
- 段違い平行棒（UB）
- 平均台（BB）
- ゆか（FX）

## ✨ 主な機能

- **技入力**: 技名・難度（A-J）・グループを選択または手動入力
- **a技ボタン**: グループなし、難度a（0.1点）の技を簡単追加
- **ドラッグ&ドロップ**: 技の順序を自由に変更
- **自動計算**: 難度点・構成要求点・技数制限を自動計算
- **組み合わせ加点**: ゆか・鉄棒で手動入力可能
- **跳馬**: 技名・技番号・Dスコアを手動入力
- **目標Eスコア**: 各種目で目標E点を設定（技数に応じた上限自動適用）
- **その他ND**: 手動で減点を追加
- **履歴機能**: Ctrl+Z/Yで操作の取り消し・やり直し
- **自動保存**: ブラウザに自動保存（リロード後も復元）
- **レポート生成**: 全種目の結果をPNG画像で保存

### 女子限定機能
- **ルール切り替え**: 標準ルール（国際大会用）と変更規則Ⅰ（日本国内用）の切り替え

## 🚀 使い方

1. トップページで男子または女子を選択
2. 種目タブを選択
3. 「技を追加」ボタンで技を追加
4. 技名を入力すると自動補完候補が表示
5. 難度とグループを選択
6. 目標Eスコアを入力
7. 自動的にDスコアと目標合計点が計算されます

## 💾 データ保存

入力データは自動的にブラウザのLocalStorageに保存されます。

- 男子データ: men_gymnastics_d_score_data
- 女子データ: women_gymnastics_d_score_data

データを削除する場合は、各ページの「保存データ削除」ボタンをクリックしてください。
